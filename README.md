# 批量文件重命名工具 v2.1

一个功能强大的 Windows 桌面批量文件重命名软件，支持多种重命名模式的自由组合。

## 功能特性

### 核心功能
- **倒序排列文件** - 反转文件列表顺序
- **删除指定文字** - 从文件名中删除特定文字
- **查找替换** - 支持普通替换和正则表达式替换
- **添加前缀/后缀** - 在文件名前后添加指定文字
- **序号重命名** - 按序号批量重命名（支持补零）
- **大小写转换** - 全部小写、大写、首字母大写、驼峰命名
- **修改扩展名** - 批量修改文件扩展名，支持仅修改大小写（如 `.jpg` → `.JPG`）

### 特色功能
- **多选组合** - 可同时启用多个重命名功能，按顺序依次处理
- **实时预览** - 执行前预览重命名效果，绿色背景显示将被修改的文件
- **撤销功能** - 支持逐次撤销本次运行中的重命名操作；撤销失败会保留记录以便重试
- **文件过滤** - 按扩展名或关键字过滤文件
- **支持文件和文件夹** - 可选择单个文件夹或多个文件进行重命名

## 使用方法

### 方式一：直接运行 EXE（推荐）
1. 下载 `批量文件重命名工具.exe`
2. 双击运行
3. 选择文件夹或文件
4. 勾选需要的功能并填写参数
5. 点击"预览效果"查看结果
6. 确认无误后点击"执行重命名"

### 方式二：运行 Python 脚本
1. 确保已安装 Python 3.6+
2. 安装依赖：`pip install pillow`（仅生成图标需要）
3. 运行：`python batch_rename.py`

## 编译 EXE

如需自行编译 EXE：

```bash
# 安装 PyInstaller
pip install pyinstaller pillow

# 生成图标（可选）
python create_icon.py

# 编译 EXE
pyinstaller --onefile --windowed --icon=app_icon.ico --name="批量文件重命名工具" batch_rename.py
```

编译完成后，EXE 文件位于 `dist` 目录中。

## 注意事项

1. **序号重命名**时，基础名称可为空（直接使用序号）；起始序号不能小于 0，位数为 1–255
2. 重命名操作会直接修改文件名，建议先使用"预览效果"确认
3. 撤销记录只保存在本次运行中，关闭程序后不会保留
4. 发现非法文件名、重复目标或已有的其他文件时，会在执行前提示并停止整批操作
5. 支持同批文件的名称互换和连续编号；执行失败会尝试恢复原名。若文件被占用而未能恢复，程序会显示当前位置并保留撤销记录
6. 扩展名过滤支持 `.jpg,.png`、`jpg,png` 和中文逗号；忽略多余的空项
7. 功能组合顺序为：删除文字 → 查找替换 → 序号 → 前缀 → 后缀 → 正则 → 大小写 → 扩展名。文字操作仅作用于文件名主体

## 系统要求

- Windows 10/11（当前 EXE 打包版本）
- 无需安装 Python（EXE 版本）

## 版本历史

### v2.1 (当前版本)
- 修复仅修改文件名或扩展名大小写时误报重名
- 修复倒序编号时预览和执行的文件对应关系不一致
- 支持批量连续编号和名称互换，避免同批文件相互占用名称
- 修复删除空格、驼峰命名开头分隔符和扩展名过滤空项的问题
- 增加 Windows 文件名及序号参数验证，修复正则替换分组错误导致的异常
- 批量执行失败时尝试恢复原名，撤销失败保留记录，并防止撤销到其他替换文件
- 修复空文件选择刷新到旧文件夹、文件夹被移除后刷新报错的问题

### v2.0
- 新增倒序排序功能
- 新增删除指定文字功能
- 改为多选模式，支持功能自由组合
- 新增序号重命名基础名称验证
- 优化界面布局，增加滚动条

### v1.0
- 初始版本
- 支持基本重命名功能
